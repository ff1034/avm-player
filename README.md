# AVM 環景錄影播放器

汽車環景系統錄影（四路魚眼 `.ts`）播放器：環景模擬（鳥瞰）、3D 環景、四分割、單鏡頭魚眼校正、行程分組、截圖與匯出。

整個播放器就是一個 `index.html`。**影片一律從你的裝置直接讀取，截圖與匯出也存回你的裝置，不會上傳到任何地方。**

- 電腦：用 Chrome 或 Edge 開啟，按「選擇資料夾」。
- iPhone / iPad（iOS 17 以上）：用 Safari 開啟，按「選擇檔案」從「檔案」App 選 .ts（可多選）；截圖與匯出會跳出分享選單，選「儲存到檔案」。
- Android：用 Chrome 開啟，按「選擇檔案」。
- 網址後面加 `?selftest` 會顯示這台裝置的支援狀況。

車輛模型：「Honda HRV」by timadrianh（Sketchfab，CC-BY-4.0）。
